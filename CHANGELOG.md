## [1.0.0] - 2026-08-01

### Added

#### Create Directories from Text File

- Create directories from a text file
- Support for nested folder structures
- Automatic replacement of invalid Windows filename characters
- Duplicate entry detection
- Progress reporting
- Timestamped log generation

#### Create URL File List

- Generate sequential URL lists from a starting and ending URL
- Preserve original file extension (.jpg, .jpeg, .png, .tif, etc.)
- URL validation
- Output formatted for batch downloading

#### Batch TIFF to JPEG Converter

- Batch conversion of TIFF images to high-quality JPEG
- Configurable JPEG quality
- Preserve image dimensions
- Preserve filenames
- Optional recursive folder processing
- Optional overwrite of existing JPEG files
- Conversion logging
- Storage reduction summary
